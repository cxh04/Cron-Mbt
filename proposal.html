1. 项目简介 (Project Overview)

在现代软件工程中，定时任务（Cron Job）是维持系统自动化运转的核心基础设施。当前 MoonBit 语言官方生态库（mooncakes.io）在任务调度和 Cron 解析领域尚处空白。Cron-Mbt 旨在填补这一生态缺口，提供一个轻量级、类型安全且极致高效的定时任务 Cron 表达式解析与调度验证引擎。本项目充分利用 MoonBit 静态类型系统的优势以及极其快速的编译运行特性，实现对复杂时间调度规则的毫秒级解析，为 MoonBit 在后端服务、自动化脚本等成熟应用领域铺平道路。

2. 项目方向与适用场景 (Direction & Use Cases)

主攻方向：国产基础软件生态库建设、MoonBit 工具链基础设施补充。

典型适用场景包括但不限于：

  • 云原生与后端服务：用于 MoonBit 构建的 Web 服务器或微服务架构中，处理周期性的数据库清理、心跳检测或数据聚合任务。
  • CI/CD 与自动化工作流：赋能类似 actrun（MoonBit 版 GitHub Actions Runner）的自动化工具链，提供精准的工作流定时触发器。
  • 边缘计算与 WebAssembly (Wasm)：借助 MoonBit 极小的 Wasm 体积优势，在资源受限的边缘设备或 IoT 智能硬件上，部署无操作系统的独立轻量级定时调度服务。

3. 拟实现的核心功能与技术亮点 (Core Features)

  • 标准的 5 字段解析器 (Robust Parser)：完全遵循 Linux Crontab 标准，支持分钟、小时、日期、月份、星期字段。代码内置极强的容错机制，精准捕获越界与词法错误。
  • 全特征语法修饰符支持：不仅支持基础数字，还全面实现了 *（任意时间）、,（离散时间点枚举，如 1,15,30）、-（时间范围区间，如 1-5）、以及 /（步长跳跃，如 */5）等高级语法结构。
  • 高并发安全匹配引擎 (Time Matcher)：提供 expr.matches(...) API，在接收到系统时间注入时，利用纯函数设计和高效内存数组查找，做到无副作用匹配，极其适合并发环境。
  • 极致的类型安全与工程规范：完全摒弃异常抛出机制，采用 MoonBit 原生的 Result 枚举类型（Ok / Err）进行错误传递。项目已配置高覆盖率的 moon test 单元测试以及 README.md 快速起步文档，保障企业级可用性。

4. 实施路线与最终交付物 (Roadmap & Deliverables)

项目分为三个阶段稳步推进，当前已完成第一阶段的闭环验证并成功交付开源：

  • 阶段一（已交付）：完成词法分析、抽象语法树构建、边界测试、同步上架 GitHub/GitLink 并开源（采用 Apache-2.0 协议）。
  • 阶段二（规划中）：扩展宏指令（如 @hourly, @daily）支持，以及基于时间戳的 next_execution_time() 推导算法。
  • 阶段三（规划中）：接入时区（Timezone）感知与秒级（6 字段）调度支持，最终发布至 mooncakes.io 包管理平台。
